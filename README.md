# FROGGIT

**The frog that eats back.**

A 3D browser game built with three.js for the JetBrains Game Challenge. You are The Froggit — a toad who was supposed to be prey for the bees. Then you grew a tongue.

Eat bees. Chain combos. Evolve. Flip the food chain.

## Play

```bash
npm install
npm run dev
```

Open the URL Vite prints (default `http://localhost:5173`).

- **Arrow keys** — hop
- **SPACE** — attack (the tongue is coming…)

## The game

The Froggit hops across a checkerboard meadow past three houses. Bees pour in from the map corners, hunt you down, and speed up as your score climbs. Survive, fight back, and chase the high score.

Built as the course project for [Build a Game with an AI Coding Agent](https://academy.jetbrains.com/course/30327), extended for the [#JetBrainsGameChallenge](https://github.com/Mayank-CS50/Froggit).
